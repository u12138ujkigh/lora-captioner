# LoRA Captioner — 训练集打标工作台

LoRA 训练数据集批量 caption 生成工具。人物 / 服装 / 风格三类打标，DSH 网关 + 本地 Ollama 双引擎，WebUI 全流程可视化。

## 启动

双击 `run_webui.bat`（端口在文件顶部 `PORT=7860` 处改），浏览器自动打开 `http://127.0.0.1:7860`。

## 使用流程

1. **选打标类型**：人物 / 服装 / 风格（三卡片切换，字段随类型联动）
2. **选目录**：📂 打开目录浏览器，或直接粘贴路径（可勾选含子目录）
3. **填类型参数**：
   - 人物：人名（如 Yanni）或泛化主体（a young East Asian woman）+ 可选触发词
   - 服装：服装 LoRA 名称 + 触发词
   - 风格：风格 LoRA 名称（如 XiuRen_Style）+ 可选触发词
4. **选引擎**：Provider（DSH 17 渠道 + Ollama）→ 模型（带 ✓ 可看图 分组）。**免费推荐 dsh:buddy 的 buddy/hy3**
5. **开始**：▶ 全量 或勾选试跑模式（先跑前 2 张看效果）
6. 批次结束 → 预览/编辑/单张重打 → 🧹 清屏 → 下一批

## 三类打标核心原则

| 类型 | caption 要写 | caption 不写 |
|---|---|---|
| 人物 | 姿态/表情/当次服装/背景/光影/机位 | 五官、固定发型肤色、标志性造型（触发词承载） |
| 服装 | 穿着者/姿态/场景/妆发/鞋袜 | 目标服装的颜色材质剪裁 |
| 风格 | 画面内容/主体/场景/构图/客观光影 | 一切风格词（程序二次黑名单剔除） |
| 身材 | 当次服装+姿态+场景+机位（20-45词短句） | 一切体型词（hourglass/curvy/长腿/马甲线等，程序二次剔除） |

模板在 `prompt_templates/*.md`，直接编辑保存即生效。

## 功能清单

- 断点续跑（跳过已有 .txt）、试跑模式、并发 1-8 可调
- 预览面板：大图 + caption 编辑保存 + 英译中展示 + 单张重打
- 覆盖前自动备份 .bak；失败自动可重试
- SSE 实时进度 + 日志流；批统计（总耗时/平均/成功率）
- 记住上次配置；清屏进入下一批次
- 触发词可配开头/结尾拼接
- 🔍 **质检面板**：缺文件/过短/过长/触发词丢失/风格词漏网/体型词漏网/完全重复/高相似簇 + 词数分布直方图
- 📥 **多目录队列**：单目录入队或多行批量入队，批次结束自动推进，顶栏按钮显示排队数
- ✏️ **批量替换**：全词/大小写可配，先预览 diff 再落盘（.bak 备份）
- 🏷️ **文件名构图联动**：`_head/_half/_full` 自动补构图词到 caption
- ⌨️ **键盘操作**：←/→ 切图、Esc 关弹窗；日志栏点击折叠；批次完成横幅
- 🔄 引擎列表一键刷新（新拉了 Ollama 模型后点一下即可）

## 技术栈

Python 3.12 venv + FastAPI + SSE + 原生JS单页。依赖仅 fastapi/uvicorn/pillow/pyyaml/httpx。

## 注意

- ofm-free 系列模型在网关 404（无 adapter），用 buddy 渠道
- 本地 Ollama 需视觉模型（如 `ollama pull qwen3-vl:8b`）才能打标，文本模型返回空
- 密钥只从 `~/.dsh/.credentials.yaml` 读取，不落任何其他位置
