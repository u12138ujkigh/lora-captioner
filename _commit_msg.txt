Add a one-click pipeline, full config memory, and batch path lists

Pipeline
- 一键全流程 runs a list of directories in order, and each one gets the
  same two stages: upscale into 目录名_放大, then caption the upscaled
  files. Captioning therefore sees the high-resolution images rather than
  the originals, which is the point of upscaling before tagging.
- Upscale failures do not abort the run: the directory continues with
  whatever succeeded, the remaining directories still execute, and a
  final summary lists per-directory counts plus the failing file names.
- The stage hand-off frees ComfyUI's VRAM after each directory's upscale
  pass so the caption stage is not fighting the model for memory.
- Progress is polled from /api/pipeline/state and rendered per directory
  as 放大 x/y · 打标 a/b, so a multi-hour run is legible at a glance.

Config memory
- A separate ui_config.json now records the full working state rather
  than the partial snapshot last_config held: caption parameters
  including reasoning effort, upscale settings, the directory lists for
  both batch modes, and the whole pipeline configuration.
- It is restored on load, saved automatically on change with a debounce,
  and flushed on unload. The file is gitignored since it is per-machine
  state, not source.

Batch paths
- Upscale mode gets its own multiline directory list that queues several
  folders at once.
- Caption mode gets the same, feeding the existing multi-directory queue
  and showing what is queued underneath.

Also fixes a real break in the upscale path: ComfyUI's SaveImage always
writes PNG, but the result was saved under the source image's .jpg name,
so the gateway rejected the bytes with a type mismatch and every caption
in the pipeline failed. Downloads are now re-encoded to match the target
extension, and already-matching files skip re-encoding to avoid quality
loss.

Verified end to end on two directories: Yanni and Mika each produced a
768x1152 JPEG plus a caption text file containing the trigger word, with
the second directory starting only after the first finished. 36 checks
pass, including 133 balanced divs, 354 CSS blocks, and 123 ids.
